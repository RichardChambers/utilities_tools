# utilities_tools
various tools and utilities that provide some functionality but are also small and don't really
need their own repository. Several of these are investigations into some concept that
I ran across at some point and thought interesting.

Most of these are C source code.

There are various small projects investigating a particular topic of interest.

  - ArenaMemoryLib is a demonstration of memory arenas as a memory management tool
  - ClosuresAndStringLib contains a technique for closures and some string primitives
  - DoubleLinkListContainerOf contains double linked list using a technique said to come from the Linux kernel
  - FileAccessLib is a lightweight indexed file storage library
  - UsbWindows is an investigation into USB communications with the Windows API
  - FontShow is an investigation into bitmap fonts for embedded devices and small screens

Each of these has a README.md file in the folder that provides additional details about the project.
I've tried to comment the source code with some attention to details.
